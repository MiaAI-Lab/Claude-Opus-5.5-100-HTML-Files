=== DESCRIPTION ===
A full-screen, black-and-gold instrument for exploring the Mandelbrot set and its Julia sets. The fractal fills the window with smooth, continuous colouring, and the palette is mapped relative to the lowest escape value in view, so the far exterior falls to black and the coastline glows. Thin gold typography and hairline panels with corner ticks frame the image: a spaced-caps "Infinite Coastline" title, a position readout (real, imaginary, zoom in scientific notation, auto-rising iteration count, cursor or seed c, render progress and time), a bookmark panel whose live thumbnails are rendered by the page itself, and a toolbar with zoom, reset, four palette swatches (Aurum, Abyss, Magma, Pastel Dream), colour cycling, the Julia toggle and PNG export. A circular gold-ringed lens trails the cursor and shows, live, the Julia set for the point beneath it.

=== MAJOR VISUAL TECHNIQUES ===
- Escape-time kernel with smooth (continuous) iteration count, bailout radius 256, cardioid and period-2 bulb rejection and Brent-style periodicity checking
- Multi-threaded progressive rendering: the kernel's own source is packed into an inline Blob and run in a pool of Web Workers (main-thread time-sliced fallback). An 8× preview pass is followed by full-resolution strips scheduled from the centre outwards, each painted as it arrives with dirty-rect putImageData
- A float field of smooth iteration values is kept, so palette changes and palette cycling only recolour through a 2,048-entry cyclic LUT, with no recomputation
- Palette mapping t = sqrt(mu − mu_min) × density, with mu_min taken from the preview pass, so every zoom depth keeps a dark exterior and a banded, glowing boundary
- Animated zooms, pans, wheel zoom and pinch show a scaled and translated snapshot of the last frame, eased on a logarithmic scale path, until the new progressive render replaces it
- Auto iterations rising with log zoom; precision guard at the limit of 64-bit floats, with a toast
- Julia lens: a 160 × 160 live render on each pointer frame, eased to follow the cursor and flipping at screen edges; on touch screens it docks and shows the Julia set of the view centre
- Hairline gold UI: thin sans in spaced caps, italic serif accents, monospaced tabular numerals, corner-tick panels, conic-gradient palette swatches and soft corner vignettes for legibility

=== INTERACTION MODEL ===
- Click or tap to dive ×3 toward the point (animated); right-click to rise; drag to pan; mouse wheel zooms about the cursor; two-finger pinch zooms on touch screens
- Hover to see the live Julia set for that c in the lens; press J (or the J button) to make that Julia set the main view, and press J or M to return to the saved Mandelbrot view
- Bookmarks (buttons or keys 1–5): Seahorse Valley, Elephant Valley, Triple Spiral Valley, the period-3 mini-brot at about −1.7549, and the whole set; each flies there with an animated zoom
- Palette swatches form a radio group (arrow keys supported); the cycle button or C animates the colours; [ and ] change detail (iteration multiplier); + and − zoom, arrow keys pan, H or 0 resets
- Save exports the current render as a PNG through canvas.toBlob and a temporary download link, with a data-URL fallback
- A hint strip explains the gestures and fades out; toasts and a polite live region announce palette, mode and precision changes; rendering pauses while the tab is hidden; reduced motion makes zoom jumps instant
