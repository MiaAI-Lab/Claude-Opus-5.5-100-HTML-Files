=== DESCRIPTION ===
"Rule 30" is presented as a museum installation: a cream, linen-textured gallery label on the left (a textile-label serif with monospace numbers), a working loom hung on a dark gallery wall in the centre, and a column of loom controls on the right. The loom weaves an elementary cellular automaton live: every pick of the shuttle computes one new generation from the row above, and the cloth scrolls upward out of the loom as it grows, so Rule 30's chaos, Rule 90's Sierpiński triangles and Rule 110's gliders appear as jacquard fabric. In the default Kilim palette the ground is indigo #1b263b warp, the pattern floats in madder #a4161a weft with a saffron #f4a300 band every 36 picks, and cream #f1e9da selvedges and marker stripes frame it; Monochrome linen and Neon loom re-dye the whole cloth.

=== MAJOR VISUAL TECHNIQUES ===
- Woven-cell sprites pre-rendered per palette: "on" cells are weft-faced (horizontal rounded threads with gradient shading), "off" cells warp-faced (vertical threads), each with the crossing thread peeking through in a twill offset, four jittered variants and fibre flecks, so the automaton reads as jacquard
- Ring-buffer cloth canvas: each new generation is drawn once as a row of sprites (plus striped selvedges); every frame the visible cloth is blitted in at most two drawImage calls with a sub-row offset, giving smooth continuous upward motion at any speed
- The pick in progress is revealed only behind the travelling shuttle, which carries a wound bobbin of the current weft colour and trails a curved weft thread from the selvedge; the reed/beater snaps toward the fell at each completed pick
- Canvas-drawn loom: wooden cloth beam, side posts, reed dents, beater and bottom beam with grain lines; loose warp threads fan out below the fell (pre-rendered once); cloth edges are shaded like fabric under light
- Rule changes weave a cream checkered marker stripe into the cloth, so a single tapestry can record several rules in sequence
- Rule table of eight neighbourhood tiles (CSS-drawn cells in the live palette colours) with the rule's binary digits aligned beneath; wall colour, tiles and swatches follow the palette through CSS custom properties

=== INTERACTION MODEL ===
- Rule controls: number field, −/+ steppers, a 0–255 slider with a wooden shuttle-shaped thumb, Arrow Left/Right keys, and the eight clickable tiles that flip individual output bits to build any rule live
- Famous-rule chips (30, 90, 110, 184, 150, 45, 73) with an accurate one-line note for each; the label lists the rule's mirror, complement and mirror-complement equivalents as clickable links (e.g. 86, 135, 149 for Rule 30)
- First row: single centred cell or random (re-threads the loom); loom speed 1–40 picks per second; Pause/Weave (Space); Rethread (R); palettes Kilim, Monochrome linen, Neon loom (1/2/3, radio group with arrow keys); Save swatch exports the current loom as PNG
- Hovering the tapestry outlines the three parent threads and the chosen cell, shows a tooltip with the pick number, the neighbourhood → result in thread colours and the rule bit used, and highlights the matching tile in the rule table
- Rule and palette persist in guarded localStorage; the cloth is pre-woven on load so the first frame is already a full tapestry; reduced motion halves the weaving speed
